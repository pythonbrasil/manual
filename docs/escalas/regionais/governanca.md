# Processo e Governança

## Como surge um evento regional?

Diferente da Python Brasil (que tem um processo formal de candidatura via APyB), eventos regionais nascem de forma **orgânica**:

1. **Iniciativa local**: uma comunidade ou grupo de comunidades decide organizar o evento
2. **Validação com a APyB**: após definir onde será o novo evento, a organização deve [solicitar o apoio da APyB](https://apyb.python.org.br/associados/guias/como-organizar-eventos/#como-funciona) para iniciar os trâmites legais
3. **Uso da marca**: o nome deve seguir o padrão "Python [Região]" ou nome próprio (como Caipyra)
4. **Autonomia**: a equipe organizadora tem total autonomia sobre o evento

## Relação com a APyB

- A APyB **não organiza** os eventos, apenas provê a infraestrutura legal, burocrática e tecnológica para que eles aconteçam
- Ferramentas disponíveis: utilização do [Pretix](https://ingressos.python.org.br) para venda de ingressos e [Pretalx](https://talks.python.org.br) para submissão de atividades
- Comunicação: grupo dos Kahunas no Telegram para contato direto com a APyB e coordenação com a organização dos outros eventos regionais

## Diferenças entre regionais e Python Brasil

| Aspecto | Evento Regional | Python Brasil |
|---------|-----------------|---------------|
| **Processo de escolha** | Iniciativa da comunidade local | Candidatura formal via APyB |
| **Escala** | 100-500 pessoas | 500-1500 pessoas |
| **Duração** | 2-3 dias | 4-6 dias |
| **Abrangência** | Regional (estados vizinhos) | Nacional e internacional |
| **Orçamento** | R$ 50k-100k | R$ 200k-500k+ |

## Código de Conduta

- **Obrigatório**: todo evento da comunidade Python no Brasil deve adotar o [Código de Conduta da APyB](https://python.org.br/cdc/)
- Divulgue o CDC em todos os materiais e durante o evento
- Tenha um canal de denúncia claro e acessível
- A equipe organizadora deve estar familiarizada com o CDC
