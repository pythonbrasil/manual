# Manual do Big Kahuna: Guia para a organização de eventos Python

Bem vindas ao guia para organização de eventos Python!

Este guia tem como objetivo auxiliar às comunidades desde seu interesse em candidatar-se como sede, passando pela organização da conferência, até sua finalização (o pós-evento). Este também é usado como suporte textual do programa de mentoria promovido pela Associação Python Brasil (APyB) para as equipes organizadoras do evento.

Este manual cobre **todas as escalas de eventos Python**: desde meetups locais até a Python Brasil, passando por eventos regionais. Se você está começando uma comunidade ou planejando um grande evento, este guia é para você.
