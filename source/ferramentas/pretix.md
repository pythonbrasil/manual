# Pretix

## O que é
O [pretix](https://ingressos.python.org.br) é uma ferramenta opensource que a APyB disponibiliza para
os associados que desejam organizar eventos.
A ferramenta é hospedada pela APyB e pode ser utilizada de forma gratuíta.

## Requisitos
Para mais informações sobre os requisitos para poder usar a ferramenta e encontrar os links acesse:
[Guia APyB](https://apyb.python.org.br/associados/guias/como-organizar-eventos)
