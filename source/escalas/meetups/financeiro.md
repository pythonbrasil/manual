# Financeiro e Patrocínio

## Custos típicos de um meetup

| Item | Custo estimado | Observações |
|------|----------------|-------------|
| Local | R$ 0 - R$ 500 | Muitas empresas cedem gratuitamente |
| Coffee break | R$ 0 - R$ 300 | Participantes podem trazer algo, ou ratear |
| Adesivos/brindes | R$ 50 - R$ 200 | Opcional, mas fortalece comunidade |
| **Total** | **R$ 0 - R$ 1.000** | |

## Como conseguir patrocínio para meetups

1. **Empresas locais**: a primeira opção. Ofereça espaço para falar com a comunidade
2. **Rateio entre participantes**: para custos específicos (coffee, brindes)
3. **Parcerias com espaços**: empresas cedem espaço em troca de visibilidade
4. **Comunidade**: peça contribuições voluntárias via Pix ou vaquinha online

## Dica importante

**Não comece cobrando ingressos.** Meetups devem ser acessíveis. Se precisar de recursos, busque patrocínios ou rateie custos de forma transparente.

## Modelos de proposta para empresas

Para empresas, prepare uma proposta simples (1 página):
- O que é a comunidade Python local
- Quantas pessoas participam dos meetups
- O que a empresa ganha (logo, fala, networking)
- Quanto custa (valor fixo ou cobertura de custos específicos)

## Como negociar com a empresa

- Propor agradecimentos iniciais e finais para a empresa.
- Colocar algum qr-code ou cartaz sobre as vagas disponíveis.
- Colocar uma janela para apresentação de alguém da empresa falar sobre a empresa.
