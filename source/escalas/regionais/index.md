# Guia de Eventos Regionais Python

Eventos regionais são conferências de Python organizadas por e para comunidades de uma região específica do Brasil. Eles representam um passo além dos meetups, com maior escala, duração e impacto. Este guia cobre Python Norte, Python Sul, Python Nordeste, Python Sudeste, Python Cerrado e Caipyra.

## O que são os eventos regionais?

Os eventos regionais são conferências anuais organizadas pelas comunidades locais de Python em diferentes regiões do Brasil. Cada evento tem sua identidade própria, mas todos compartilham os valores da comunidade Python: inclusão, colaboração e diversidade.

| Evento | Região | Primeira edição | Observações |
|--------|--------|-----------------|-------------|
| **Python Norte** | Norte | 2023 | Abrange AC, AP, AM, RO, RR, PA, TO |
| **Python Nordeste** | Nordeste | 2013 | Abrange AL, BA, CE, MA, PB, PE, PI, RN, SE |
| **Python Sudeste** | Sudeste | 2016 | Abrange SP, RJ, MG, ES |
| **Python Sul** | Sul | 2017 | Abrange PR, SC, RS |
| **Python Cerrado** | Centro-Oeste | 2018 | Abrange GO, DF, MT, MS |
| **Caipyra** | Interior de SP | 2016 | Foco no interior paulista |

## Roadmap sugerido

### 12 meses antes

- [ ] Definir data
- [ ] Definir local
- [ ] Montar equipe organizadora
- [ ] [Solicitar apoio da APyB](https://apyb.python.org.br/associados/guias/como-organizar-eventos/#como-funciona)

### 10 meses antes

- [ ] Criar identidade visual
- [ ] Montar e divulgar plano de patrocínio
- [ ] Lançar site do evento

### 6 meses antes

- [ ] Abrir primeiro lote de ingressos
- [ ] Iniciar divulgação ativa
- [ ] Convidar keynotes
- [ ] Cotar fornecedores

### 4 meses antes

- [ ] Começar a divulgar os keynotes
- [ ] Abrir segundo lote de ingressos
- [ ] Começar a fechar contrato com os fornecedores

### 3 meses antes

- [ ] Abrir Call for Papers
- [ ] Iniciar produção de materiais (camisetas, crachás, adesivos)

### 2 meses antes

- [ ] Avaliar submissões e montar grade preliminar
- [ ] Fazer estimativa do coffee-break

### 1 mês antes

- [ ] Finalizar e divulgar grade e palestrantes
- [ ] Abrir terceiro lote de ingressos
- [ ] Confirmar quantidade do coffee-break

### 2 semanas antes

- [ ] Abrir inscrições dos tutoriais
- [ ] Confirmar voluntários para o dia do evento
- [ ] Testar equipamentos e estrutura

### Semana do evento

- [ ] Enviar orientações para palestrantes e ministrantes
- [ ] Enviar e-mail com detalhes logísticos para participantes
- [ ] Preparar kit do participante
- [ ] Montagem da estrutura

### Durante o evento

- [ ] Credenciamento
- [ ] Execução do evento
- [ ] Desmontagem

### Pós-evento

- [ ] Prestação de contas financeira
- [ ] Agradecimentos públicos
- [ ] Compartilhamento de fotos e vídeos
- [ ] Documento de lições aprendidas

## Checklist final

- [ ] Código de Conduta divulgado em todos os materiais
- [ ] Canal de denúncia do CDC claro e acessível
- [ ] Site do evento atualizado com todas as informações
- [ ] Grade de palestras definida e divulgada
- [ ] Voluntários escalados para o dia do evento
- [ ] Equipamentos testados (som, projeção, transmissão)
- [ ] Local bem sinalizado (indicação de salas e auditórios)
- [ ] Coffee break e alimentação com opções veganas/vegetarianas
